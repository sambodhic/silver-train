# R Cubed Designs

A minimal, responsive company website for R Cubed Designs LLC. Plain HTML and CSS, with no build step or JavaScript required.

## Preview

Open `index.html` in a browser, or serve this directory:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Hosting

Static files are served from the repository root using GitHub Pages.

Typography uses Google Fonts, with local system fonts as a fallback.
