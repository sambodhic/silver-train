# R Cubed Designs

A minimal, responsive company website for R Cubed Designs LLC. Plain HTML and CSS, with no build step or JavaScript required.

## Preview

Open `index.html` in a browser, or serve this directory:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Publish

Upload `index.html`, `styles.css`, and `favicon.svg` to a static web host. Connect `rcubeddesigns.fyi` using your host's custom domain instructions and enable HTTPS.

Before publishing, create and verify the `developer@rcubeddesigns.fyi` mailbox (or update both email links in `index.html` to an active business address). Confirm the company description is accurate. The site displays the legal entity name in the About section and footer.

Once the website is live, use `https://rcubeddesigns.fyi` as the organization website. Website publication does not itself guarantee Apple verification.

Typography uses Google Fonts, with local system fonts as a fallback.
